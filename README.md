# 💰 Трекер бюджета

**Простое веб-приложение для учёта личных доходов и расходов.**
Добавляй траты, следи за балансом, смотри диаграммы и выгружай данные в CSV.

---

## ✨ Возможности

- 💸 **Учёт расходов и доходов** с категориями и комментариями
- 📊 **Две круговые диаграммы** — отдельно для расходов и доходов
- 📅 **Фильтр по месяцам** — смотри статистику за любой период
- ✏️ **Редактирование и удаление** записей
- 🌙 **Тёмная тема** с сохранением выбора
- 📥 **Экспорт в CSV** — выгружай данные в Excel
- 💾 **База данных SQLite** — всё сохраняется между запусками

---
